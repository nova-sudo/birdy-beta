Alerts: options

Two parts of /alerts don't map onto an existing ds component. Pick one option in each group. Every field, channel, action and the Ask Birdy tab stay; only the layout changes.

Group 1 · Triggered tab: per-client alerts

A "Per client" rule can fire for several clients at once. Today the rule shows as one row that expands in place into one row per client, each with Evaluate, Snooze client and Dismiss. All three options use the new progress bar (purple, amber within 20% of the threshold, red once crossed).
